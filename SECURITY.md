# Security policy

Modules run as root on the hosts they manage, so a flaw in one matters.

Please do not report security problems in public issues. Use GitHub's
private reporting instead: on this repository's
[Security tab](https://github.com/nxtw/fleetreeve-modules/security/advisories/new),
choose "Report a vulnerability". Say which module and version is affected,
how to reproduce it, and what an attacker could do with it.

Fixes are made on the latest version. A problem in fleetreeve itself is
reported at [nxtw/fleetreeve](https://github.com/nxtw/fleetreeve/security/advisories/new).
